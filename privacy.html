Privacy Policy

Effective date: November 21, 2026

This page describes how Sylos handles information for the Sylos software and this website. It is written for clarity, not as legal advice.

Local-first software

Sylos is self-hosted migration software that runs only on machines you control. You choose the source and destination. Sylos reads files and metadata from services you connect and writes them where you choose. There is no Sylos-operated central server that stores your files, migration history, credentials, or user accounts.

What stays on your device

When you run Sylos, data related to the install lives locally on that machine, including:

  • Application data under the OS app-data directory for Sylos (for example org.sylos.app)
  • Local admin and user accounts you create for that install
  • OAuth and SFTP credentials for cloud and remote hosts you connect
  • Migration databases, settings, and operational state

An install master key is stored in your operating system keyring. Per-migration secrets are wrapped and kept with that install’s local data.

To remove local data, delete the Sylos application data directory for that install and/or uninstall the software. To revoke cloud access, use the provider’s account settings (for example Dropbox, Google, Microsoft, or Box) in addition to removing local credentials.

Third-party services

When you connect a cloud provider or other remote system, traffic goes between your machine and that provider. Those providers process data under their own privacy policies and terms. Sylos does not sit in the middle as a hosted relay for your files.

Google Drive support expects you to use your own Google Cloud OAuth client (bring-your-own-app). Other providers may use Sylos-registered OAuth apps when the binary you run was built that way; you can still replace those credentials with your own in Settings.

What we do not collect

The Sylos project does not operate Sylos cloud accounts for you. The current product does not send telemetry, analytics, crash reports, or update checks to Sylos. File contents and credentials are not transmitted to Sylos project infrastructure as part of normal use.

This website

This site is a static site hosted on GitHub Pages. We do not run first-party analytics or advertising cookies on these pages. Visiting the site may still involve GitHub’s hosting infrastructure (for example standard web server logs). See GitHub’s privacy statement for how GitHub handles that.
