Why Sylos?

Preview before anything moves

See what will copy, skip, or change. Search big folders, tweak the plan, then start when you feel ready.

Pick up where you left off

Progress is saved on your computer. Pause, close the app, or hit a hiccup, then come back without starting over.

Goes as fast as it safely can

Speeds itself up automatically, without slamming into cloud limits or overloading your computer.

Catches awkward file names

Spots names that would break on another drive or cloud, suggests better ones, and lets you fix them all at once.

Stays on your machines

Your files never pass through our servers. It runs where you install it: free, open source, no subscription.

Keeps a clear record

Each move is a saved job you can look back on, not a one-and-done copy that forgets what it did.

Frequently Asked Questions

Is this just a graphical user interface for Rclone?

No. Sylos is built from the ground up as its own application, with a unique file transfer engine and different workflows.

Key differences include: Sylos gives you granular control over each operation, lets you preview, review, and save transfer plans before execution, and maintains detailed records for every action. Sylos also supports features and connection methods beyond those of Rclone and is designed for reliability, transparency, and human-friendly review.

What if I don't want to use a web based UI?

We are working on a Terminal UI interface for Sylos currently as an optional replacement to the web based UI for terminal savvy users. We are aiming to have it ready before the official Version 1.0 launch.

We also plan on building out SDK functionality to support automated migrations and sync jobs later on. Scripting and automation is on the roadmap but will be after the initial release.

What is the stance on AI contributions?

AI usage is allowed but we ask that the contributor fully understands the code they have submitted, as well as making sure the code is rigorously tested. We also ask that, if your contribution is user-facing, your contribution meets certain quality standards and does not seem like AI slop.
